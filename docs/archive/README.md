# Archive

This directory holds historical project documents — source material from
early consultations and framework design discussions that informed the
current CryptoSieve architecture.

## Contents

### `framework-3.0-initial-consultation.txt`

The original Persian-language framework-merge consultation (August 2023)
that defined CryptoSieve's 8-phase analysis pipeline. This document merged
two earlier framework specifications into the unified Discovery → Screening
→ Evidence → Evaluation → Scoring → Investment → Decision → Output pipeline,
preserving key concepts: Project Quality ≠ Token Quality ≠ Investment
Attractiveness, the 5 scoring axes, P/R + P/F + P/T valuation multiples,
and the Revenue ≠ Fees principle.

Retained as a historical record of the project's analytical foundation.
